Ghost Architect™ Local 7.4.10 September 23, 2026 2 min read By Ernst J. Wisner

Cleaner reports, a fleet that hands work on sooner, and Unlimited for Enterprise

Finding headings now carry the finding's own title, never the template's words or labels like (Batch 2), and a finding the findings file lists once is printed once."dummy" and "YOUR_API_KEY" as if they were secrets, then reading the hidden value as proof of a real secret. Those findings came out CRITICAL. Ghost now leaves aluation now.

A finding now points at the file it is about: code before a README or CHANGELOG, and a file the finding names before one it only lists. A cited path with the wrong directory shows the file Ghost actually read. A finding that calls a function unused, when the code calls it, is set aside with the lines that call it.

In a fleet, a peer whose relayed call has just come back is offered the next call at once, instead of looking full until its next health reading. The Scan Queue no longer says a peer is holding nothing while one of this hub's calls is running on it.

On a CPU-only machine each call's speed is now compared with what that machine did before at a similar prompt size, so a normal speed for a larger prompt is no longer called slow. The warning says what it was compared with.

An Enterprise licence now says Unlimited on the license banner, System Status and the Users page, instead of 10000.

Full technical release notes for 7.4.10 are on the changelog, alongside every other Ghost Architect™ Local release.
