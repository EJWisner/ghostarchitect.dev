The Scan Queue named the wrong machine

The Scan Queue's "Running on" column is supposed to name the machine whose model is working on a scan right now, and to name a peer hub while a call is out on it. For a POI scan's write-up sluation now.

That stage is registered under its own name so the page can tell it apart from the analysis stage, but every event recorded for the same call, including the line saying which peer it was sent to, is written under the scan's original mode. The lookup asked for the wrong name, found nothing, and the column fell back to naming this hub, even when the line one row up in the same log said the call had gone to the peer.

The work really was on the peer; the page reported the silence as "here" instead of "unknown". The lookup now asks for the call's real mode, the one the log was always written under.
