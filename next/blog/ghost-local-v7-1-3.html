The Linux installer

The installer installs Node.js when the machine has none it can use, ending three cases the same way instead of in three different dead ends.

It fetches the pinned version from nodejs.org, verifies it against the published SHASUMS256.txt, and copies into /usr/local: no package manager is run, no repository is added, and no remote script is piped into a shell. If the download cannot be verified, nothing is unpacked and the refusal says so.
