// frequently asked · Ghost Architect™ Local

What is Ghost Architect™ Local, and how is it different from Ghost Architect™ Cloud?

The same scans and the same reports, running entirely on hardware you own against a model server you run. Ghost Architect™ Cloud sends your code to Anthropic's API with your own key and bills a monthly membership; Local sends nothing anywhere, needs no API key, and is an annual licence per seat band. Choose Local when the code cannot leave the building, or when a per-token bill is the wrong shape for your team.

Do I need an Anthropic API key for Ghost Architect™ Local?

No. Local runs against your own model server: Ollama, vLLM, LM Studio, Jan.ai or any OpenAI-compatible endpoint. The model, the weights and every prompt stay on your network.

How does the evaluation trial work?

Request the download, install it, and the trial starts inside the product on first use, registered against that install; the product tells you the day it ends. No card. Convert during the trial and your first year is half price.

Which Local tiers include zero egress?

Agency ($12,499 a year, 15 seats) and Enterprise ($24,999 a year, unlimited seats). Zero-egress mode refuses, at the code level, any model endpoint that would send source code off the machine, and ships with the egress inventory that proves what the product can and cannot reach. Solo and Small Team run against your own model server too; they do not carry the enforced refusal.

How is Local delivered, and how do I upgrade?

Directly from us, not through a package registry. Buy a licence and your key and a download link arrive by email the moment you pay; for the evaluation trial, EJ sends the tarball or gives your GitHub account access to the delivery repository. Every tarball has a published SHA-256 to check before you unpack it. On Linux the installer provisions a service account and two systemd units (the portal and the scheduler). You upgrade by re-running the installer on the new tarball; your configuration, scan history and licence persist. The changelog lists every release.

What hardware do I need?

Whatever runs your model server. Ghost Architect™ Local measures its own pass times on your machine and estimates from them, so every time estimate you see is yours and not a benchmark from ours. Larger models read code more carefully and take longer per pass; the product's LLM Status page shows your machine's speed, memory and context window so you can see the trade-off before a long scan.

// frequently asked · Ghost Architect™ Cloud

What is Ghost Brief™ and which tiers include it?

Ghost Brief™ is the governed AI remediation pipeline built into Ghost Architect™. After any scan, Ghost converts your findings into a validated, blast-radius-aware prompt pack -- a ghost-brief.json file your AI coding agent (Claude Code, Cursor, Copilot) can execute immediately. Ghost Brief™ is included in Ghost Pro Max ($99/mo), Ghost Team Max ($799/mo), and Ghost Enterprise Max ($2,500/mo). All three tiers gate the feature at the license level -- no manual configuration required.

What's the difference between Ghost Open and Ghost Pro?

Ghost Open is free forever and requires no signup -- install and run immediately with your own Anthropic API key. For a guided Pro Max experience with Ghost Watcher, Ghost Brief, and the Ghost Portal running on your real repo, start a 7-day free trial at ghostarchitect.dev/trial. Ask a Question and Recon are free forever, unlimited. You also get four free deep reports across Points of Interest, Blast Radius, Conflict Detection, and Prompt Triage. Inheritance Audit is Pro and above. When you upgrade, Ghost Pro removes the report cap and adds project intelligence: project label tracking, baseline comparison, remediation velocity, the Project Dashboard, Compare Reports, and Ghost Partner™ profile support with per-profile billing rate overrides.

Do I need my own Anthropic API key?

Yes. Ghost Architect is BYOK (Bring Your Own Key). This is by design: your code goes directly from your machine to Anthropic's API. We never see it. A typical scan costs $0.23 in Anthropic API usage. Most Pro users run 10 to 20 scans per month, which is $2 to $5 in API costs on top of the membership. You can verify this yourself: the cost of every scan is printed in the output.

How do I get access after subscribing?

After subscribing through Stripe, your license key is generated automatically and emailed to you within seconds. Install Ghost Open from npm if you haven't already, then run ghost --activate <KEY> to unlock Pro features. The key remains valid as long as your membership is current. If you cancel or your membership lapses, the key deactivates.

Can I get a demo before subscribing?

Yes. Email support@ghostarchitect.dev or connect on LinkedIn and we'll schedule a 15-minute Teams call with a live scan of a sample codebase.

What languages and platforms does Ghost Architect support?

Ghost Architect works on any codebase, any language, any platform, including PHP, JavaScript, TypeScript, Python, Ruby, Java, and more. It's framework-aware and analyzes code structure, dependency relationships, configuration files, and integration patterns regardless of what stack you're running.

Can I use Ghost Architect on a client's private repository?

Yes. Ghost Architect supports private GitHub, GitLab, and Bitbucket repositories. Authenticate with a personal access token, Ghost clones the repo locally, runs the scan, and removes the local clone when done. Your client's code never touches any third-party infrastructure beyond your own Anthropic API key.
