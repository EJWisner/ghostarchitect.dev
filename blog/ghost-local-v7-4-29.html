Ghost Architect™ Local 7.4.29 September 28, 2026 2 min read By Ernst J. Wisner

Ghost Architect™ Local scanned itself, and we fixed what it found

The model now yields to the rest of a Windows machine, a busy model no longer reads as a dead one, and findings contradicted by the code they name are set aside with the line that answers them.

On a Windows machine running its model on the processor, Ollama's model runner took every core for each call and nothing else got a turn: the health check, the portal, email, a remote login. Ghost Local now runs the runner below normal priority. Logins that could not connect in 100 seconds connect in two, and calls are no slower.

Our own scan of Ghost Architect Local reported HIGHs that the code it named contradicts: timeouts said to be missing from functions that supply one, empty answers said to pass as success beside code that throws on them. Those are now read against the named code and set aside with the line.

Every set-aside finding appears in the appendix, the counts agree everywhere a report states them, and the real issues our scan found in our own code are fixed in this release.

Full technical release notes for 7.4.29 are on the changelog, alongside every other Ghost Architect™ Local release.
