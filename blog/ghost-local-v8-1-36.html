Ghost Architect™ Local 8.1.36 November 17, 2026 2 min read By Ernst J. Wisner

A Recon report lists where the secrets are

Run a Recon on a codebase you have just been handed, and its report lists every access token, password and private key Ghost recognizes, by file, line and type, with no part of any value shown.

Ghost already read every file with the rules that remove secrets before any model sees your code, and showed you the first 40 on screen. Now the Recon report lists every one, and so does its JSON sidecar.

Besides the code, Recon reads the files where secrets are usually kept that a scan does not send to a model: .env, .npmrc and .netrc files, private key files, credentials and secrets files, Terraform, Docker and CI files. They are read for the list only.

The report says how many files were read, names any it read only in part, and says plainly that it lists only the secrets Ghost recognizes. It names no product, so a white-labeled report stays yours.

A scan run with --no-interactive now applies --exclude and --exclude-presets, as an interactive scan always has; before, the files you excluded were loaded anyway.

This release also gives back the escape a redacted value took inside a JSON string, so a JSON file keeps parsing, wherever it is certain the backslash is not part of the value.
