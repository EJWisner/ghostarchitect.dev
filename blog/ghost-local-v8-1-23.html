Ghost Architect™ Local 8.1.23 November 12, 2026 2 min read By Ernst J. Wisner

A pinned model loads when the machine has room, and every finding keeps its file

8.1.23 places a pinned model by what the hub has loaded now, counts the memory Ollama frees, stops false Ollama alerts, and keeps each finding's file when the model leaves out the Files: line.

A project pinned to a model that was not loaded when its scan began could end after the first call, told the hub had no memory for a model it had just loaded. Each placement now reads what the hub has loaded at that moment, and the memory check counts what Ollama gives back when it replaces an idle model. On a Mac hub a refusal says how short the hub is, and administrators can allow a load that is slightly short with Load Shortfall, off by default.

Larger models often name a finding's file only in its text. Such findings reached the report citing no file. Each pass now asks for the Files: line, and where a model leaves it out a finding takes the file its own text names, when that is a file the pass read. Merges, the summary and a scan you take up again keep those files.

A health check that ran late because the portal was busy no longer counts as Ollama not answering, and an idle portal no longer reads every queued report each minute while the Ghost reviewer waits.
