A Recon report lists where outside code runs

Run a Recon on a codebase you have just been handed, and its report lists the scripts the site loads from other companies' servers, by file, line and server, and marks the tag managers and testing tools that can load code that is not in the codebase at all.

Attacks on websites increasingly arrive through a trusted outside script: a testing tool, a tag manager or an analytics snippet that every page already allows. Recon now shows where those scripts are, read straight from the code with no model.

Each script is marked when it is a tag manager or testing tool, when its file's name says checkout, login, payment or account, and when a script tag has no integrity check. The report also says which files name a Content Security Policy.

Only the server's name is printed, never the rest of an address, and the report says plainly that it shows where outside code runs, not what that code does. It names no product, so a white-labeled report stays yours.
