Ghost Architect™ Local 8.1.25 November 16, 2026 4 min read By Ernst J. Wisner

The model makes the calls. Ghost's code checks them.

Every AI code tool has the same weak spot: one model step feeds the next, and a mistake in step one quietly becomes a confident sentence in the report. Ghost Architect™ Local is built the other way round. Its code reads your files exactly. The model makes the decisions. And the code checks the decisions before anything is built on them.

Checked before it is used

Since 8.1.24, the scan plan, the executive summary, a Ghost Partner™ profile, Prompt Triage's deep checks and the Ghost reviewer's verdicts are each read by code before Ghost uses them. An answer that cannot be used is asked for once more, with what was wrong. If it is still wrong, Ghost falls back to what its code alone can say, and the report's Analysis Completeness section tells you that it did.

Nothing dropped in silence

8.1.25 fixed the reader that turns a model's answer into findings. A finding whose title began with a category's own word was taken for a heading and lost, along with every finding after it. Now it is read, a finding is counted once, and anything the reader cannot read as a finding is printed in an appendix, so no finding the model wrote leaves the report without a word.

The same evidence, the same report

For IP evidence reviews we went further. Since 8.1.17, the report is written by Ghost's code from the files and its own checks, so the same codebase gives the same report above its appendices, word for word, whatever the model answers. We ran it six times on the same code and got six identical reports.

Why it matters to you

A report you put in front of a client, a board or opposing counsel has to say the same thing tomorrow, and every line has to come from the code. That is what this design is for: the model brings judgment, the code brings exactness, and a person signs off on what Ghost learns. We are still extending the checks to every hand-off between steps, and each one ships as its own release.
