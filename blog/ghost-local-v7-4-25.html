Ghost Architect™ Local 7.4.25 September 27, 2026 2 min read By Ernst J. Wisner

Findings are read more carefully against the code

A missing check that is already there is set aside, a finding that says it is not a bug is INFO, and a loose quote of a real line is kept for review, not removed.

Each of these came from a recent open-source scan: a parser flagged for checks it already makes, a limitation described as a bug, and a real shell injection removed over a misquoted line.

A scan asked for a set number of passes now runs that many in total, even when it is paused for an update partway through.

A finding that only touches release or CI tooling, which runs on maintainers' machines rather than users', is now rated MEDIUM at most.
