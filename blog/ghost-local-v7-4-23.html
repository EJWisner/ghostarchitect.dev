Ghost Architect™ Local 7.4.23 September 27, 2026 2 min read By Ernst J. Wisner

A folder named 3rdparty is someone else's code

Folders named 3rdparty, 3rd_party or 3rd-party are now treated as copied-in code, like third_party, and their findings stay out of the score.

A scan of magic_enum scored a finding against the doctest framework it copies into test/3rdparty. That code belongs to other authors, so it no longer counts against the project.

Full technical release notes for 7.4.23 are on the changelog, alongside every other Ghost Architect™ Local release.
