Ghost Architect™ Local 8.1.26 November 13, 2026 3 min read By Ernst J. Wisner

See every secret Ghost replaced, before you send anything

Since 8.1.26, when a scan loads your files, Ghost Architect™ Local lists each secret it replaced: its type, its file and its line. Read the list before you send a scan to a cloud model.

Redaction you cannot see is redaction you have to take on faith. This release shows its work.

The list

  • Each secret by type, file and line, with at most the first four characters of a value of 12 characters or more, never more than a quarter of it. Nothing is shown for a shorter value, or for anything in a private key or certificate.
  • On the screen, up to 40, with how many more. A background scan writes the same list to its log, up to 200 lines, since nobody watches its screen.
  • A token in a file's name is redacted in the list, as everywhere else Ghost prints a name.

The words say what is true

Ghost Architect™ replaces the secrets it recognizes with [REDACTED:TYPE] markers, and may miss others. A run that found none says it found no secret it recognizes, and that it may have missed some. When the place of each secret in a file cannot be worked out, the summary says in how many files that was, and those secrets are redacted all the same. Nothing is guessed.

Why it matters

For a Local only project the list is a record. For a project you allow to use a cloud model, it is the last look before code leaves your network. A secret Ghost did not recognize is not on the list, and is sent as it is in your code. Read the list, and if something is missing from it, keep that project local.
