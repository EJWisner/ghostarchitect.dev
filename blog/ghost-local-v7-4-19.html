Ghost Architect™ Local 7.4.19 September 26, 2026 2 min read By Ernst J. Wisner

Busy machines read as busy, Bats tests are read, and three more wrong claims are checked

The Scan Queue says when a machine is busy with a call. Bash test suites are read, and wrong claims about error handling, unused code and caches are set aside.

A machine in the fleet that is too busy running a call to answer a status check now reads as busy with that call, and for how long, rather than as gone.

Bats test files are read and counted. A file the model made up is dropped from a finding's list. Findings that call Rust error handling silent, a built-by-name function unused, or a cleared cache never cleared are set aside with the lines that answer them.
