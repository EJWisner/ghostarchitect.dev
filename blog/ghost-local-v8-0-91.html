Ghost Architect™ Local 8.0.91 October 24, 2026 2 min read By Ernst J. Wisner

An IP evidence review reports IP findings, in the code's words

8.0.91 keeps an IP evidence review to findings about provenance, licensing, patents and copying, each stated in what the code and its files show.

A finding that is not about IP is listed in an appendix of its own. A sentence that calls the codebase's own code external or third-party, or proprietary when no file says so, is left out, and so are the model's judgements such as fragile or tightly coupled. A request to settle a point with source the codebase already holds is not printed.

A licence, copyright or patent line is not rated down for being in a comment, the findings file says what the report says, and the rules apply to small codebases scanned in one pass too. The manual inside the download is stamped 8.0.91.

Full technical release notes for 8.0.91 are on the changelog, alongside every other Ghost Architect™ Local release.
