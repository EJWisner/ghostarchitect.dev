Ghost Architect™ Local 8.1.13 November 6, 2026 5 min read By Ernst J. Wisner

No access token or private key in anything Ghost writes or sends

Code holds secrets. A scanner that reads code will meet them. Ghost Architect™ Local 8.1.13 makes sure that none of them comes back out: not in a report, not in a log, not in an email, and not on your screen.

Codebases hold credentials where they should not be: a token in a deploy script, a key committed by accident and deleted later, a password in a test fixture. Finding them is part of the job. Repeating them in the report that finds them would be a new leak.

Everywhere Ghost writes

An access token, password, API key or private key in a file, a file or folder name, a git remote, a branch or a project label is replaced before it reaches the report (PDF, Markdown and text), the findings file, SARIF, the report's file name, logs and records, portal pages and downloads, the REST API, the CLI, or the terminal while an answer streams. A long credential is replaced whole.

Everywhere Ghost sends

Scan emails, webhooks, SIEM lines, Slack and Teams cards, pull request comments, Jira issues, hub-recovery alerts, client reports, and what a spoke sends its hub carry no token.

Private keys in every common form

PEM keys of any label, encrypted keys, OpenPGP, SSH2 and PuTTY keys, keys stored as base64 (in a kubeconfig or a Kubernetes Secret, wrapped or not), URL-encoded keys, JSON Web Keys and .NET RSAKeyValue keys. A complete key is replaced from its BEGIN line to its END line, whatever lies between. A key cut off part way is replaced as far as its key data goes.

What you see is what was saved

When a streamed answer quotes a private key, the screen pauses at that point and shows the rest, redacted, when the answer ends. The screen always matches the saved copy.

A pattern written wrong takes nothing down

If one of your own custom redaction patterns is written wrong, pages, the API, logs and records carry on with the built-in rules and your other patterns. Anything that would leave the machine is refused until the pattern is fixed, and each refusal names the pattern.

What it is not

Redaction replaces the secrets Ghost recognizes. A secret it does not recognize is not replaced. That is why the next releases added a way to check it on your own hub, and a list of everything it replaced.
