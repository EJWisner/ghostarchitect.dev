Ghost Architect™ Local 7.4.17 September 26, 2026 2 min read By Ernst J. Wisner

Paused scans are not counted as cancelled, duplicate findings are merged, and copied-in code is left out

Scans paused for an update no longer count as cancelled, one finding written two ways is listed once, and code copied in from another project is left out and named.

The daily report counts only scans that ended, and says separately how many were paused for an update and carried on. A scan someone actually cancels still reads cancelled.

Two findings that cite the same files and say the same thing in slightly different words are now one finding. Findings that differ by a name stay separate.

A folder that is another project, such as a test framework copied into a tests folder, is left out when the repository says whose it is, and the report's coverage line names it and why.

Full technical release notes for 7.4.17 are on the changelog, alongside every other Ghost Architect™ Local release.
