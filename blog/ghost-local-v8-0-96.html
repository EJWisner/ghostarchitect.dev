Ghost Architect™ Local 8.0.96 October 26, 2026 2 min read By Ernst J. Wisner

An IP review gives the same answer each time

8.0.96 has the analysis model answer an IP review only with the area of each finding and the lines it cites, so every sentence in the report is written by Ghost Architect™ Local from the files themselves.

Every model call of an IP review runs at temperature 0 with a fixed seed, so the same codebase on the same build gives the same findings, and the Analysis Environment section says how each call was asked and where it ran. No rating in an IP review is above MEDIUM, and every file name it prints is a file in the scanned folder.

Findings set aside for the same reason share one line with a count, and the scan shows its progress while it writes the report. The manual inside the download is stamped 8.0.96.
