Ghost Architect™ Local 8.1.35 November 16, 2026 2 min read By Ernst J. Wisner

A password in a string inside a string is redacted

JSON written inside code, a command written inside a string, and JSON in a JSON string are now read the way their program reads them, so a password inside them is replaced.

Such a string writes its own quotes with a backslash. Ghost read it as written, so a password inside it reached your model and Ghost's reports. Of the password forms Ghost already recognized, written inside a JavaScript string, the release before showed the password in 96 of 105. This release shows it in none, and the same holds inside Java, Python, JSON, YAML and a shell's bash -c.

The new reading runs after every rule and only adds: nothing Ghost replaced before can be shown now, and a line that holds no password is changed no more than the same line written out plainly.

A line that a rule reads only in another kind of file, such as a Makefile line written inside a JavaScript string, may still be shown. Chapter 6 of the manual lists the limits.

This release also replaces a key's private value that is mostly a token of small letters, where an answer is cut off in the middle of the key. Our release tests found it on a random draw; it is now checked every time.

Full technical release notes for 8.1.35 are on the changelog, alongside every other Ghost Architect™ Local release.
