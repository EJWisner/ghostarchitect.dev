Ghost Architect™ Local 7.4.8 September 24, 2026 2 min read By Ernst J. Wisner

Severity you can trust, and a backup that pauses the scans

Ghost was hiding values like "dummy" and "YOUR_API_KEY" as if they were secrets, then reading the hidden value as proof of a real secret. Those findings came out CRITICAL. Ghost now leaves a placeholder as it is written and still hides anything that could be real.

A finding whose every cited file is test or example code is now MEDIUM at most, because that code does not run in production. The finding says what it was first rated and why it was lowered.

The severity rubric now says that CRITICAL and HIGH need a production path, that a placeholder is not a secret, and that code which logs an error and returns an error response is reporting it, not swallowing it. The first scan of each project after this update analyses every file again; later scans reuse that work as before.

The daily backup now pauses the scans instead of waiting for a quiet machine that may never come. Each scan pauses after the pass it is on, the backup runs, and the scans restart on their own. Every queue screen says "pausing for backup" while it happens.

The daily usage report lists each project once, with its findings scan by scan and a count of the attempts that ended early.
