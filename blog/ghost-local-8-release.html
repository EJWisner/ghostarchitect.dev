Ghost Architect™ Local 8 is out of beta

With 8.0.87, Ghost Architect™ Local 8 left beta and became the release line. Here is what 8 brings, in one place, for anyone still on 7 or still deciding.

The 8.0.0 beta opened on September 29 with one idea: you don't need to train a model, you teach the tool. Over the next four weeks the beta built a great deal around that idea. From 8.0.87 on, 8 is what we release.

What 8 brings

  • The learning system. Your reviewers record verdicts on findings with a written reason, bundle them into Learning Requests, and after a second person approves, a versioned rule set changes how that project's future scans are judged. Every step is logged and can be rolled back.
  • Corrected reports, without a new scan. A report your team has judged can be re-issued as a labelled corrected version beside the original. The original is never changed.
  • The model switch and the model cluster. See every model on every machine, send each job to the model that suits it, and add a cloud model as a member only when you choose to.
  • A data boundary per project. Each project is Local only or Cloud allowed, and every report says which.
  • Reports that say what they read. What was read and what was not, and for a git checkout the commit, branch and working-tree state.
  • What counts as the product. Findings that cite only test, example or documentation code are set aside by a scope setting you can change, and the report says the setting set them aside. A secret in a test file is still counted.
  • Load Qualifying, a scan mode that reads the code for patterns known to fail as traffic or data grows, judged in context and cited to their sources.
  • Export to Jira, a report's findings or one finding, from the portal or the REST API, or as a CSV for Jira's own importer when your hub runs with zero egress.

Evidence reviews a lawyer can read

The last beta weeks went to the IP evidence review. In 8.0.87 a review walks only the checks its profile names, never general engineering rows such as dead code. Its summary is made of the findings themselves, one sentence each with severity and file, most severe first, instead of the model's own prose. A finding names a company, project or license only where the cited lines name it. These are the habits a report needs before counsel will read it.

Moving from 7

Local 8 is the release line, and a 7.x release is no longer cut. The manual's 8.x edition covers every change, chapter by chapter, and Ask about Ghost Architect™ answers questions about it on your own model.
