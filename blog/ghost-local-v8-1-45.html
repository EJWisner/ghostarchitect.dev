Ghost Architect™ Local 8.1.45 November 19, 2026 2 min read By Ernst J. Wisner

Real findings a cloud scan made are no longer set aside

Every finding a cloud model raised in six scans we checked by hand was real, but some were set aside as unverified. The verifier now sees the code it is asked about.

We checked every finding of six scans of three public projects by hand against the code. Every finding the cloud model raised was real, yet the verifier had set some aside as unverified, including the two most serious.

The verifier shows a model the code a finding is about, and it showed at most 12,000 characters whatever the model. A cloud model was asked about functions it was never shown. In the Cloud API position it now sees up to 64,000 characters; a local model sees what it saw before.

Two checks that set findings aside without a model now read the claim more closely, so they answer what the finding is actually about.
