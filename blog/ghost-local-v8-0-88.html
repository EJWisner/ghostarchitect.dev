Ghost Architect™ Local 8.0.88 October 23, 2026 2 min read By Ernst J. Wisner

Saved analysis follows the questions

8.0.88 makes sure a rescan never hands back analysis that was asked a different question: a new version, an edited profile or a new rate card means the work is done again.

Ghost Architect™ Local saves each pass of a scan so that a rescan of unchanged code is fast. From 8.0.88 a saved pass is reused only for exactly what it was asked: the version's instructions, the Ghost Partner™ profile and the rates. The first scan of each project after updating analyses every file in full once.

If you ran an evidence review on unchanged code under 8.0.85, 8.0.86 or 8.0.87, run it again on 8.0.88. The manual inside the download is stamped 8.0.88.

Full technical release notes for 8.0.88 are on the changelog, alongside every other Ghost Architect™ Local release.
