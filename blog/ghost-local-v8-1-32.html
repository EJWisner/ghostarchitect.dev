Ghost Architect™ Local 8.1.32 November 15, 2026 2 min read By Ernst J. Wisner

A key's value that looks like a token is redacted whole

8.1.32 reads private keys before any token rule, so a key's private value that happens to hold a token's shape is replaced whole.

A private value of a JSON Web Key is random, so now and then it holds the shape of another service's token, a Google API key or a GitHub token. Ghost Architect™ Local replaced that token first and then read the key's value only up to it, so when Ghost loaded your files the rest of the value could reach a model or a report as written.

This release reads private keys before any token. The whole value is replaced when Ghost loads your files, in an answer as it streams, and in everything it writes or sends. We tested it by planting each of the 16 token shapes Ghost recognizes inside each private value of real keys, written as JSON, JavaScript, Python and YAML.

If you think a key like this was sent before this release, replace it.
