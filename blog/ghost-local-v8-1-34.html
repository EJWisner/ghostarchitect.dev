Ghost Architect™ Local 8.1.34 November 16, 2026 2 min read By Ernst J. Wisner

Three passwords and a token Ghost missed are redacted

This release replaces an npm token written with an underscore before it, a SQL password that holds or ends in a backslash, and a batch file's password set with another command on its line.

Each of these reached your model and Ghost's reports as written. An npm token written build_npm_ followed by the token was read by every token rule but npm's; a SQL password with a backslash in it stopped the SQL rules; and set "DB_PASSWORD=..." followed by & echo done stopped the batch file rule.

Every rule Ghost already had keeps its pattern and its place. Each new reading is a rule of its own that runs after them and reads only what they left, so nothing Ghost replaced before can be shown now. We tested that against the release before on more than 60,000 drawn lines.

A password inside a string inside a string, such as JSON written inside code, is not covered yet. It is the next release.
