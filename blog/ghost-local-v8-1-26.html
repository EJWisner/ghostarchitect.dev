Ghost Architect™ Local 8.1.26 November 13, 2026 2 min read By Ernst J. Wisner

See each secret Ghost redacted, by file and line

8.1.26 lists every secret Ghost replaced when it loads your code, so you can see what it took out before your code is read.

When a scan loads your files, Ghost now lists each secret it replaced: its type, the file and the line, and at most the first four characters of a long value so you can recognize it. Nothing is shown for a short value or for a private key.

A scan that runs in the background writes the same list to its log, so a scheduled or API scan has it too.

Ghost says plainly what it does: it replaces the secrets it recognizes and may miss others. What it redacts has not changed in this release.

Full technical release notes for 8.1.26 are on the changelog, alongside every other Ghost Architect™ Local release.
