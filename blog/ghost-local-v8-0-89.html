Ghost Architect™ Local 8.0.89 October 24, 2026 2 min read By Ernst J. Wisner

Evidence reviews state only what the code shows

8.0.89 keeps an evidence review to what the files say, and adds the facts a reader needs where a finding speaks about the codebase's own code.

In an evidence review, each finding now keeps what the code shows and leaves out sentences about what it could lead to or what it means legally. A sentence that quotes a file, or reports what a file says, is always kept.

When a finding calls code under one of the codebase's own declared modules a dependency, vendored or third-party code, Ghost Architect™ Local adds a note read straight from the files, with no model: the module line, each file in that folder with its copyright, license and origin lines, and any manifest that requires the module. The finding stays as written, and the reader sees both. The manual inside the download is stamped 8.0.89.

Full technical release notes for 8.0.89 are on the changelog, alongside every other Ghost Architect™ Local release.
