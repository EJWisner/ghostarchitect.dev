Ghost Architect™ Local 8.1.12 November 3, 2026 2 min read By Ernst J. Wisner

Zero-egress mode is off unless you turn it on

8.1.12 changes the installers' zero-egress question so that pressing Enter leaves zero-egress mode off.

The macOS and Windows installers now ask "Enable zero-egress mode? [y/N]". Pressing Enter leaves it off; answer y to turn it on, or turn it on at any time in Admin Console, System Settings, Zero-Egress Mode. We strongly recommend it for air-gapped and regulated work. The question says what zero-egress mode turns off and what an install sends without it.

Running the installer again on a hub that already has zero-egress mode on keeps it on unless you answer n. The Linux installer never turns it on and now says so on its last screen. The manual inside the download is stamped 8.1.12.

Full technical release notes for 8.1.12 are on the changelog, alongside every other Ghost Architect™ Local release.
