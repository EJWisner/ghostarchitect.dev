Ghost Architect™ Local 8.1.33 November 15, 2026 2 min read By Ernst J. Wisner

A secret in a file's name is not sent to a model

This release reads everything sent to a model once more, just before it is sent, so a token or password in a file's or folder's name is replaced like one in its contents.

Ghost Architect™ Local redacted each file's contents as it loaded your files. But what a model reads names each file it holds, so a file called token-ghp_ followed by a real token sent that token to your local model as written. Calls to a cloud model were already covered.

Now every model call is read for secrets just before it is sent, on every path a call can take, with each file read under its own name so nothing else changes. A call that cannot be read in full is not sent. We tested it by planting each of the 16 token shapes Ghost recognizes in file and folder names.

If a name holding a secret reached a model that is not on a machine you control, replace the secret.
