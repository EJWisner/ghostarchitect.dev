Ghost Architect™ Local 7.4.27 September 27, 2026 2 min read By Ernst J. Wisner

Error handling is read the way it was written

A catch that re-throws is not silent, a catch that says why is LOW at most, and a timeout with a default is not missing, in JavaScript, Java, C#, PHP, Python and Ruby.

Each of these came from recent open-source scans: a re-throwing catch called a silent swallow, a documented fallback called silent, and a request timeout said to be infinite when every request starts at 30 seconds.

Findings like these are now set aside with the line that answers them, or rated LOW with the code's own comment quoted, so a reader can judge it.

Python except and Ruby rescue blocks are read the same way as catch blocks.
