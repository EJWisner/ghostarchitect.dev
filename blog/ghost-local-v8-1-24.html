Ghost Architect™ Local 8.1.24 November 12, 2026 2 min read By Ernst J. Wisner

A cloud scan works on the newest Claude models, and every answer is checked

8.1.24 builds each cloud request for the Claude model it goes to, counts what the provider bills, and reads every answer a scan asks a model for in code before it is used.

In the Cloud API position, requests to Claude Sonnet 5.5, Opus 5.5 and the other newest models were refused, because they set a sampling temperature those models no longer take. Each request is now built for its model: temperature only where it is taken, an effort level where it is taken, and room for the model's thinking within its own limit. The cost estimate counts thinking, which is billed as output, and the newer tokenizer, which counts about 30% more tokens.

The scan plan, the executive summary, a Ghost Partner™ profile, Prompt Triage's deep checks and the Ghost reviewer's verdicts are each read by code before they are used. An answer that cannot be used is asked for once more with what was wrong, and then falls back to what the code alone can say. The report's Analysis Completeness says when that happened.

Our cloud tests now run against stand-ins that refuse what the real API refuses, so a request it would refuse fails a test before it reaches you.

Full technical release notes for 8.1.24 are on the changelog, alongside every other Ghost Architect™ Local release.
