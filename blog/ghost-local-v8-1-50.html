Ghost Architect™ Local 8.1.50 November 21, 2026 2 min read By Ernst J. Wisner

A cloud model plans by its own window

A ceiling set for the machine's own model no longer limits a cloud scan. A cloud scan plans by the cloud model's window.

On a machine whose config.yaml sets contextCeiling for its own model, a scan in the Model Switch's cloud position was held to that ceiling too, so a cloud model with a 1,000,000-token window was planned for 32,000 tokens.

The ceiling now holds the machine's own model only. A cloud scan plans by the cloud model's window, which cloud.contextWindow sets, and says where that window came from.
