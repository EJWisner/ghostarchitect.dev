Most software IP disputes start years before anyone files. In a file nobody read.

A copied library with someone else's copyright line. A license file that no longer matches the code that points to it. A patent mention in a comment. None of it is hidden; it is simply never read until it is evidence.

The problem is growing. Black Duck's 2026 Open Source Security and Risk Analysis found license conflicts in two-thirds of the 947 commercial codebases it audited, the highest share in the report's history, and points to AI coding assistants that reproduce open source code without its license.

Today you see the code when the dispute arrives. Now you can see it every week.

// what the review reads

The IP evidence review.

  • 01

    A provenance inventory, read with no model

    Straight from the files: every copyright holder and the years each is named with, the license of every file, patent mentions, lines that say where code came from, and license files that do not line up with the code that points to them.

  • 02

    Findings that quote their line

    Each finding names the file and the line and quotes it. Ghost Architect™ writes every finding itself from lines it has checked. No sentence in the report is the AI model's own wording.

  • 03

    Rated, and held back when the code says so itself

    Each finding carries a rating. When the code openly discloses the very thing a finding is about, the rating is capped at MEDIUM rather than raised as an alarm.

Repeatable by design. In our own test on a well-known open source library, three runs on the same build came back identical, and we checked every line of every run.

// where the code goes

To your firm. And no further.

Your IT keeps a read-only copy of each client's repository on the firm's machine. Ghost Architect™ Local reviews that copy with every outbound connection switched off at the code level, using a model that runs on hardware you own. No AI company, no cloud service and no other client ever sees the code.

Air-gapped here means the analysis: while Ghost reads and reviews the code, nothing leaves the machine. Bringing the code from your client to your firm is the one step that crosses a network, over a read-only key your client controls and can revoke at any time.

For the client whose code may not leave its own building at all, the same review runs on the client's machine instead, and only the report comes to you. How zero egress works →

// what it checks, and what it does not

We will always tell you what it can and cannot do.

  • 01

    It reads what the files declare

    Copyright lines, license texts and identifiers, notices, patent mentions, and the comments that say where code came from, across every file in the tree.

  • 02

    It does not match code against the world's open source

    Ghost Architect™ Local does not compare your client's code against a database of open source projects, so it will not catch code copied with its license notice removed. Tools built on such a database can. This is the review your firm runs every week, and it says plainly what it read.

  • 03

    It does not draw legal conclusions

    It records what the files say. Whether that is infringement, a license breach or nothing at all is your judgment, and the report leaves room for it.

// questions attorneys ask first

Questions attorneys ask first.

Is the analysis air-gapped if the code comes from my client's repository?

The analysis is. While Ghost Architect™ Local reads and reviews the code, nothing leaves the firm's machine, and no AI company or cloud service is involved. Bringing the code from your client to your firm is the one step that crosses a network, over a read-only key your client controls. For a client whose code may not leave its building at all, the review runs on the client's machine and only the report comes to you.

Does an AI model write the findings?

No. The provenance inventory is read straight from the files with no model at all, and each finding is written by Ghost Architect™ Local from lines it has checked. No sentence in the report is the AI model's own wording.

Will the same code give the same report?

Yes. The same codebase on the same build gives the same report every time. When two reviews differ, the code changed.

Can the reports carry our firm's name?

Yes. With a Ghost Partner™ profile the report carries your firm's name and your methodology instead of ours. We set up the IP review profile with you.

Does it replace a full open source audit before an acquisition?

No. It reads what the files declare; it does not compare the code against a database of open source projects, so it will not find code copied with its license notice removed. Use it as the review your firm runs every week, alongside a database audit when a deal calls for one.

What does the firm need to run it?

A machine running macOS, Linux or Windows with enough memory for a local model, and a model server such as Ollama on that machine or your network. The product measures its own speed on your hardware and states the basis of every time estimate it gives.
