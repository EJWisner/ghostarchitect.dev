// what the snapshot would show, and what the full review adds

Seven answers, each with the next question attached.

Each section would tell you what the snapshot found and what a full review would add, so you can decide whether the full review is worth paying for on this codebase.

01

Size and shape

Snapshot

Files, lines and languages, and the folders where most of the code lives.

The full review adds

Every file read and graded, with coverage stated as files read out of files present.

02

Stack reality

Snapshot

The frameworks, runtimes and versions the repository itself declares, not the ones in the pitch deck.

The full review adds

An end-of-life map with dates, version drift across services, and a 90-day modernization roadmap.

03

Key-person concentration

Snapshot

How much of the code rests on a few authors, and whether they are still active.

The full review adds

Concentration per subsystem, and flags on the contributors who have already left.

04

Dependencies

Snapshot

Each declared dependency, with its license and end-of-life status.

The full review adds

License classification across the dependency tree, copyleft exposure in commercial code, and abandoned components.

05

Ownership and licenses

Snapshot

Copyright holders, licenses, patent mentions, and license files that do not match the code that points to them.

The full review adds

The intellectual property evidence review: rated findings that quote the file and line, with no legal conclusions.

06

Activity

Snapshot

How recently and how often the code changes.

The full review adds

Where the risk concentrates, what a change would reach, and the trend scan over scan.

07

What a full review would take and cost

Snapshot

The size of the job, how long a full review would take with the basis of that estimate stated, and its price.

The full review adds

The review itself, with the snapshot’s $99 credited toward it.

// price and limits

$99, credited toward the full review.

If you go ahead with the full review, what you paid for the snapshot comes off its price. If you do not, you keep the snapshot and know why you walked away.

A first look, not a review. It would read what the repository declares. It would not grade the code, it would not match code against an open source database (so it cannot find copied code with the license stripped), it is not a CVE scanner, and it draws no legal conclusions.
