// it tells you what it did not do

A report that admits what it did not read.

We will not tell you a local model is smarter than a frontier model. It is not, and you already know that. What we will tell you is that Ghost Architect™ does not let the model make claims it cannot back.

  • 01

    Nothing counted is not zero

    A report says 8 of 52 files analyzed and claims nothing about the other 44. When a scan stops before it finishes counting, the record says nobody counted, never zero findings.

  • 02

    A verdict that hangs on one word says so

    The report prints what the score would be if one finding were graded one band lower. When the verdict flips on that word, it tells you, instead of burying the fragility in an average.

  • 03

    Walk into the SOC 2 renewal with records, not assurances: every scan, who ran it, on what and how it ended, in signed CSV and PDF exports, with a hash-chained audit log the product verifies in front of you.

// hub and spokes

How it runs, and what it runs on.

A hub and as many spokes as you enroll. The hub holds the model server, the queue and the Fleet page; a spoke is any machine that runs scans and reports them back. Everything talks over your LAN.

Hardware, stated as measured, not as a brochure. Our own machines run qwen3.5:9b, and we are testing a 27B model. One measured run: an intellectual property evidence review of a 16-file open source library took 32 minutes 29 seconds on a MacBook Air (Apple M3, 24 GB) running qwen3.5:9b through Ollama, and three runs gave identical reports. A real application codebase takes longer; a bigger machine is faster; a bigger model reads more carefully and takes longer per pass. The product measures its own pass time and prints the basis of every estimate it makes, so the second scan on your hardware is sized from the first.

What you need: macOS 13 or later, Linux, or Windows 10 or later; Node.js 24 or later; a model server on your network with a model pulled: Ollama, vLLM, LM Studio, Jan.ai or any OpenAI-compatible endpoint you point it at. The installer checks the OS and Node floors and refuses rather than guessing. The Linux installer is verified on a fresh machine for every release.

// questions people ask first

Questions people ask first.

Does anything leave my network?

One call, once: license activation sends the license key and an install id to ghostarchitect.dev and gets a signed license back. Nothing from the codebase is in it. While the product analyzes code, nothing about the code leaves the machine, and the egress inventory it prints lists every destination that could exist and shows each one switched off. The Cloud API position, on your own key, is off by default, and a project set to Local only never uses it.

Which models does it use?

Whatever your model server serves: Ollama, vLLM, LM Studio, Jan.ai or any OpenAI-compatible endpoint. Our own machines run qwen3.5:9b, and we are testing a 27B model. The LLM Status page shows the model, quantization, context window, memory and measured speed, so you can see what a model change did.

Is it the same as Ghost Open™?

No. Ghost Open™ is the single-user CLI on npm, and it sends code to Anthropic’s API on your own key. Local is a separate product delivered directly by us as a tarball, installed with its own installer, licensed per team, and it runs on your own model. Its Cloud API position is off unless you turn it on.

How long does a scan take?

It depends on your hardware, your model and the codebase, and the product tells you before you commit: the estimate names its basis, and once you have run a few passes it is measured from your own machine. One measured example: an intellectual property evidence review of a 16-file open source library took 32 minutes 29 seconds on a MacBook Air (Apple M3, 24 GB) with qwen3.5:9b. A full scan of a real application codebase takes longer, so start it in the background; the Fleet page and email tell you when it is done.

Can I run it in CI or on a commit hook?

Yes. The CLI has a non-interactive mode, it registers a pre-push hook that runs the Ghost Triple Crown™, and the REST API on the hub is documented at /api/v1/docs on your own install.

Do I get the source?

The product ships as source in the tarball; that is what the installer installs. It is licensed, not open source, and the license is signed and verified on the machine.
