What it can and cannot do

What this audit does not do.

The Ghost Inheritance Audit™ is a pre-engagement triage. It surfaces risk patterns so a qualified engineer or diligence team knows where to look. Specifically:

  • It identifies risk patterns. It does not prove exploitable bugs.
  • It does not run CVE scans against transitive dependencies.
  • It does not match code against an open source database, so it will not find copied code with the license stripped.
  • It does not test runtime behavior, integration paths or production data flows.
  • It does not replace a full security audit, penetration test or operational due diligence.

The report’s value is in showing where to look, not in delivering final answers. Have qualified people validate the findings before any acquisition or modernization decision.

Frequently asked

Common questions, answered.

How do I send you my codebase?

Three options. Easiest: a GitHub repository link (a private repository with a read-only collaborator invite works well). Alternatively, a Git clone URL with read-only credentials, or a ZIP file at a temporary cloud storage link. We sign an NDA on request before any code transfer.

Where does my code go during the audit?

To us, and to the model that does the synthesis step. Today that step runs through Anthropic’s Claude API, under Anthropic’s own data policy, and everything else runs on our own machines. Nothing is shared, sold or used for training by us, and a signed NDA is available on request. If your code may not go to any AI company, tell us before you order, or run the audit yourself in Ghost Architect™ Local on your own hardware.

What if my codebase is huge?

No size cap. Whether it is one custom module or a hundred vendor extensions, your audit covers the complete scan. Larger codebases take longer to process, and the 48-hour window holds.
