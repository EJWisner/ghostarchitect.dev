// frequently asked · Ghost Architect™ Local

What is Ghost Architect™ Local, and how is it different from Ghost Open™?

Every Ghost Open™ mode plus teams, projects, Ghost Partner™ profiles and automatic checks on every commit, running on hardware you own against a model server you run. Ghost Open™ sends your code to Anthropic’s API with your own key. Local runs on your own model, and unless you turn on its Cloud API position, nothing about your code leaves your machines. Choose Local when the code cannot leave the building, or when a per-token bill is the wrong shape for your team.

Do I need an Anthropic API key for Ghost Architect™ Local?

No. Local runs against your own model server: Ollama, vLLM, LM Studio, Jan.ai or any OpenAI-compatible endpoint. You need a cloud provider key only if you choose to turn on the Cloud API position, and then it is your own key.

How does the evaluation trial work?

Request the download, install it, and the trial starts inside the product on first use, registered against that install; the product tells you the day it ends. No card. Convert during the trial and your first month is half price.

Which Local tiers include zero egress?

All of them. Zero-egress mode comes with every license, Solo to Enterprise. It refuses every outbound destination at the code level and prints the egress inventory that proves what the product can and cannot reach.

Can I license it just for the month of a deal or a matter?

Yes. It is monthly and you can cancel any time, so a deal advisor or an expert can license it for the month of a deal or a matter and stop when it closes.

Can you help us install it?

Yes. We will walk through the install with you on a call: your hands on the keyboard, your code on your own machine. Ask for an install call.

How is Local delivered, and how do I upgrade?

Directly from us, not through a package registry. Buy a license and your key and a download link arrive by email the moment you pay; for the trial, the download link is emailed to you straight away, or we give your GitHub account access to the delivery repository. Every tarball has a published SHA-256 to check before you unpack it. On Linux the installer provisions a service account and two systemd units (the portal and the scheduler). You upgrade by re-running the installer on the new tarball; your configuration, scan history and license persist. The changelog lists every release.

What hardware do I need?

Whatever runs your model server. Ghost Architect™ Local measures its own pass times on your machine and estimates from them, so every time estimate you see is yours and not a benchmark from ours. One measured example: an intellectual property evidence review of a 16-file open source library took 32 minutes 29 seconds on a MacBook Air (Apple M3, 24 GB) running qwen3.5:9b. Larger models read code more carefully and take longer per pass; the LLM Status page shows your machine’s speed, memory and context window so you can see the trade-off before a long scan.

// frequently asked · Ghost Open™

What does “no license fee for one person” mean?

Ghost Open™ is source-available under the Business Source License 1.1. Its Additional Use Grant lets one person use it in production free of charge, on their own machines, for their own work or their employer’s or clients’ work. Every single-user mode is on, with no quotas, no trial clock and no license key. An organization using it through a shared, multi-user or hosted deployment needs a commercial license; for teams, that is Ghost Architect™ Local.

Do I need my own Anthropic API key?

Yes. Ghost Open™ is BYOK (Bring Your Own Key) by design: your code goes directly from your machine to Anthropic’s API. Our public sample scan cost $0.2372 in Anthropic API usage, and the cost of every scan is printed in the output, so you see your own.

What is not in Ghost Open™?

Anything that needs more than one person or a server: teams, projects and project tracking, the Project Dashboard, Ghost Partner™ profiles and white-label reports, and automatic checks on every commit. Those are in Ghost Architect™ Local, along with your own model on your own hardware.

Can I get a demo?

Yes. Email support@ghostarchitect.dev or connect on LinkedIn and we will schedule a 15-minute Teams call with a live scan of a sample codebase.

What languages and platforms does Ghost Architect™ support?

Any codebase, any language, any platform, including PHP, JavaScript, TypeScript, Python, Ruby, Java and more. It reads code structure, dependency relationships, configuration files and integration patterns whatever stack you run.

Can I use Ghost Open™ on a client’s private repository?

Yes, if your client allows its code to go to Anthropic. Ghost Open™ supports private GitHub, GitLab and Bitbucket repositories: authenticate with a personal access token, it clones the repository locally, runs the scan and removes the clone when done. The code goes to Anthropic’s API on your own key, which makes Anthropic a third party to it. If your client forbids that, use Ghost Architect™ Local.
