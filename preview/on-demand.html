Six steps. You ask, agree and pay. We do the rest.

    Tell us the codebase, about how many files it has and when you need the report. Access is a read-only key or collaborator invite on the repository: you control it and can revoke it at any time.

  2. We size it and quote the price and the time

    Before anything runs, we size the codebase and reply with the price, the delivery time, a payment link and our one-page agreement. You decide whether to go ahead.

  3. Agree to one page and pay

    Reply “I agree” to the email with your quote, or tick the terms box when you pay. One page: what we review, who receives the report, liability capped at the fee you paid, and your code deleted when we deliver. Read the one-page agreement →

    Ghost Architect™ runs on our own hardware with no cloud AI. Every report passes our approval step before it leaves us.

  5. You get the report, under your brand

    Delivered only to the people you named, with your firm’s name and methodology on it.

  6. Run it again when you need it

    No fixed schedule. When the code changes or the deal moves, ask for the same project again and it runs again end to end. The same code gives the same report, so a change in the report is a change in the code.

// what you get

One report: the intellectual property evidence review.

A provenance inventory read with no AI model: copyright holders and the years each is named with, the license of every file, patent mentions, comments that say where code came from, and license files that do not match the code that points to them. Then rated findings that quote the file and line. No legal conclusions; those stay with you.

Measured on our own hardware: an intellectual property evidence review of a 16-file open source library took 32 minutes 29 seconds on a MacBook Air (Apple M3, 24 GB) running qwen3.5:9b through Ollama, and three runs gave identical reports. Larger codebases take longer, which is why we quote the delivery time before you pay. What the intellectual property evidence review reads →

// where your code goes

Your code comes to us and no one else, is reviewed on our own machines with no cloud AI, and is deleted when we deliver.

That is a different promise from Ghost Architect™ Local. With Local, the product runs on your machines, so your code never leaves your building at all. // what it can and cannot do

We will always tell you what it can and cannot do.

It can

Read what the files declare

Copyright lines, license texts and identifiers, patent mentions and origin comments, across every file in the tree, and quote the line behind each finding.

It cannot

Find copied code with the license stripped

It does not match code against a database of open source projects. Tools built on such a database can.

It is not

A CVE scanner, a binary analyzer or a lawyer

Keep your security scanner. It does not analyze binaries, and it draws no legal conclusions.
