// how a run would work

Six steps, and only the first two need you.

  1. Sign one page

    A one-page agreement: what we review, who receives the report, liability capped at the fee you paid, and your code deleted when we deliver.

  2. Give us read-only access

    A read-only key or collaborator invite on the repository. You control it and can revoke it at any time.

  3. We size it and quote the delivery time

    Before anything runs, we size the codebase and tell you when the report will arrive. You decide whether to go ahead.

  4. We run the review on our machines

    Ghost Architect™ runs on our own hardware with no cloud AI. Every report passes our approval step before it leaves us.

  5. You get the report, under your brand

    Delivered only to the people you named, with your firm’s name and methodology on it.

  6. Run it again when you need it

    No fixed schedule. When the code changes or the deal moves, ask for the same project again and it runs again end to end. For intellectual property evidence reviews, the same code gives the same report, so a change in the report is a change in the code.

// the first review we would offer

Intellectual property evidence reviews first.

A provenance inventory read with no AI model: copyright holders and the years each is named with, the license of every file, patent mentions, comments that say where code came from, and license files that do not match the code that points to them. Then rated findings that quote the file and line. No legal conclusions; those stay with you.

Measured on our own hardware: an intellectual property evidence review of a 16-file open source library took 32 minutes 29 seconds on a MacBook Air (Apple M3, 24 GB) running qwen3.5:9b through Ollama, and three runs gave identical reports. Larger codebases take longer, which is why we would quote the delivery time before you pay. What the intellectual property evidence review reads →

// where your code goes

Your code comes to us and no one else, is reviewed on our own machines with no cloud AI, and is deleted when we deliver.

That is a different promise from Ghost Architect™ Local. With Local, the product runs on your machines, so your code never leaves your building at all. With On Demand, a copy comes to us for the length of the job. If your code may not leave your building under any circumstances, On Demand is not the service for you, and Ghost Architect™ Local is.

// what it can and cannot do

We will always tell you what it can and cannot do.

It can

Read what the files declare

Copyright lines, license texts and identifiers, patent mentions and origin comments, across every file in the tree, and quote the line behind each finding.

It cannot

Find copied code with the license stripped

It does not match code against a database of open source projects. Tools built on such a database can.

It is not

A CVE scanner, a binary analyzer or a lawyer

Keep your security scanner. It does not analyze binaries, and it draws no legal conclusions.
