// ghost-brief.json

What is in a Brief?

A plain JSON file your coding assistant reads directly. The safest wins ship first, so your team banks progress before touching anything broad.

  • prompts[]

    Sorted by how far each fix reaches: surgical fixes first, broad changes last. Your assistant works in the safest order.

  • blast_radius

    surgical / moderate / broad: how many parts of the codebase this change could affect.

  • files.primary

    The exact files to change. Your assistant reads this list and stays inside it.

  • files.do_not_touch

    Keeps your assistant out of vendor code, core framework files and third-party modules, so a fix never turns into a fork.

  • validation_hints

    A checklist your assistant can verify after the fix: no existing tests break, and the change stays inside the listed files.

  • severity

    critical / high / medium / low, carried over from the original finding.

  • source_mode

    Which scan produced the finding: poi, conflict, fix-forecast and more.

  • estimated_agent_hours

    A rough, summary-level estimate of assistant time for the whole Brief. Treat it as a planning number, not a measurement.

// frequently asked

Does Ghost Brief™ write code?

No. Ghost Brief™ writes the fix plans; your coding assistant makes the changes and your team reviews them. Ghost Architect™ never touches your code, and the Brief is a plain JSON file you control completely.

Which coding assistants does it work with?

Any assistant that accepts a prompt: Claude Code, Cursor, GitHub Copilot or any other. ghost-brief.json is a plain JSON file. Read it, pass the prompts to your assistant, check the hints. No proprietary integration required.

What is Blast Radius™ and why does it matter?

Blast Radius™ is how far a change reaches: how many parts of your codebase it could affect. Ghost Brief™ orders the plans by it, surgical fixes first and broad changes last, so your assistant works in the safest order. A surgical fix stays inside one file: the smallest change you can make. A broad change ripples across the system and needs more care. The ordering is done for you.
